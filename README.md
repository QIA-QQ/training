# AI 产品经理培训演讲材料

这是可直接发布到 GitHub Pages 的静态站目录。

## 入口

- `index.html`：演讲主课件

## 目录

- `assets/`：课件中嵌入和可点击放大的案例图片
- `materials/`：附件材料，包括产品 Demo、PRD、培训主文档和 Skill 文档
- `materials/skill/`：三个 Skill 文档目录

## 发布到 GitHub Pages

1. 将本目录下所有文件上传到 GitHub 仓库。
2. 在仓库 Settings → Pages 中选择发布分支。
3. 如果仓库根目录就是本目录内容，入口会是 `https://<用户名>.github.io/<仓库名>/`。
4. 如果放在仓库子目录，请在 Pages 配置中选择对应目录，或把本目录内容移动到仓库根目录。

不要只上传 `index.html`，否则图片和附件链接会失效。
